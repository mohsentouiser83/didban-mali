# نتیجه بررسی بسته مرجع

تاریخ: ۲۰۲۶/۱۰/۲۵ — نسخه `fixture-1`

**۳۱۸ کنترل سازگاری فایل‌های ذخیره‌شده پاس شد.** جزئیات هر کنترل در [گزارش ماشینی](validation-report.json) ثبت است.

| مورد | نتیجه |
|---|---|
| ورودی اصلی | هشت فایل Excel/CSV مرتبط، دو حساب بانکی و دو دوره |
| توازن دفتر و کنترل مانده بانک | پاس؛ مانده دفتر و بانک هر حساب برابر است |
| شاخص‌ها و مانده فاکتورها | با JSON ثابت و خلاصه Excel برابر |
| تاریخ برش | دریافت پس از دوره از مانده تاریخی و برآورد در تاریخ مبنا کنار گذاشته شد |
| پیش‌بینی | دریافت ۶۰۰، پرداخت ۷۷۰ و مانده پایان ۲٬۶۲۸ ریال پس از دو پاسخ صریح |
| نمونه ظرفیت | ده فایل، بیست هزار ردیف، مرجع‌های یکتا و مانده صفر |
| هویت و خروجی | حفظ صفر آغازین در فایل Excel، hash اصل فایل، مبلغ رشته‌ای API و خروج امن متن فرمول‌مانند کنترل شد |
| F01–F15 | داده و انتظارها آماده؛ روابط عددی و حالت‌های مرجع بررسی شدند |
| T01–T14 | مراحل و انتظارها آماده؛ آزمون یکپارچه اجرا نشده است |
| Excel | پیش‌نمایش سیزده شیت ساخته‌شده بررسی شد؛ فایل تکراری نسخه یکسان بانک است |

این نتیجه درباره داده مرجع و اسکریپت مستقل بررسی است. موتور جدید، صف، قفل هم‌زمان، جداسازی شرکت‌ها، کیفیت تفسیر مدل، مرورگر، مصرف واقعی API، بار پنج کاربر، نصب و بازیابی در این کار آزموده نشده‌اند. XLS قدیمی، قالب‌های واقعی همه بانک‌ها/نرم‌افزارها، ماکرو و نمونه بدافزار نیز تأیید نشده‌اند.

حسابدار هنوز مرجع و سیاست‌های باز مالی را تأیید نکرده است. آستانه‌های تاریخچه وصول فقط متعلق به این سناریو هستند. هیچ فراخوانی مدل یا تغییر داده کسب‌وکار انجام نشد.

گام بعدی: بررسی مالی این مرجع و سپس ساخت آزمون‌هایی که خروجی پروژه تازه را با همین انتظارها مقایسه کنند.
