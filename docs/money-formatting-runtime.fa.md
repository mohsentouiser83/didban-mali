# نمایش سه‌رقمی مبالغ — ۲۰۲۶-۱۰-۳۱

تصمیم دائمی کاربر در `AGENTS.md` و `design.md`: جداکنندهٔ هزارگان کاما است؛ مانند `10,000` و در نمایش فارسی `۱۰,۰۰۰`. گروه‌بندی فقط نمایش است و مقدار مالی، واحد، علامت، اعشار و اصل منبع را تغییر نمی‌دهد.

## مسیرهای مشترک

- `apps/web/lib/money.ts`: گروه‌بندی رشتهٔ دقیق، تبدیل ارقام ورودی فارسی/عربی و قالب‌بندی مبالغ دارای واحد پول در متن. تاریخ و شناسه‌ها مبلغ تلقی نمی‌شوند.
- قالب‌بند نتایج، از جمله شاخص‌ها، جدول‌ها، شواهد، نمودارها، نقدینگی، مطالبات/بدهی‌ها، تطبیق‌ها، تسویه‌ها، گزارش‌ها، حقوق و بودجه، از گروه‌بندی مشترک استفاده می‌کند. ستون‌های شش‌گانه مبلغ تراز نیز در بازبینی ورودی پوشش دارند.
- `MoneyInput` کنترل مشترک مبلغ است: متن قابل ویرایش سه‌رقمی، مقدار فرم بدون جداکننده، حفظ محل ویرایش و اعتبارسنجی با قواعد همان فرم. در فرم‌های تعهد، تخصیص، پرداخت حقوق، مبالغ قرارداد/کارکرد/قواعد/محاسبه حقوق، معافیت/سقف پلکان مالیات و بودجه مدل استفاده می‌شود. نرخ و تعداد روز/ساعت همچنان کنترل عددی خود را دارند.
- مبلغ پاسخ دستیار و پرسش مانده بانک هم گروه‌بندی می‌شود. متن مبالغ دارای واحد در پاسخ‌های ذخیره‌شده دستیار هنگام نمایش قالب‌بندی می‌شود؛ اصل پاسخ بازنویسی نمی‌شود.
- PDF مالی و حقوق از گروه‌بندی رشته‌ای مشترک استفاده می‌کنند. PDF فارسی با IRANYekanX تعبیه‌شده و شکل‌دهی راست‌به‌چپ باقی می‌ماند.
- XLSX مالی/مدیریتی/حقوق تا ظرفیت دقیق ۱۵رقمی Excel از سلول عددی با قالب `#,##0` و اعشار متناسب استفاده می‌کند؛ مبلغ بزرگ‌تر متن سه‌رقمی دقیق است. شناسه‌ها و متن شبیه فرمول همچنان متن‌اند. JSON شواهد، اصل فایل، CSV خطا و مقادیر API قالب دادهٔ دقیق قبلی را حفظ می‌کنند.

این تغییر گزارش‌ها و فایل‌های خروجی تاریخی را بازنویسی نمی‌کند؛ خروجی‌های تازه از قالب جدید استفاده می‌کنند.

## شواهد بررسی

- ۳۵ آزمون کلاینت و ۳۹ آزمون Python مرتبط با گزارش، حقوق، مالیات و پاسخ مدل موفق شدند؛ پوشش شامل مبلغ بلند، اعشار، تبدیل ریال/تومان، صفر/ناموجود، شناسه و ایمنی متن Excel است.
- بررسی TypeScript، ESLint و Ruff و ۴۸۲ کنترل قرارداد موفق بودند. ساخت وب موفق بود.
- مرورگر داخلی Codex در محیط PostgreSQL/وب/API مستقل مصنوعی: نمایش و ذخیره سقف بودجه با هشت رقم اعشار، ورود ارقام فارسی، ویرایش کنار کاما، رد اعشار نامعتبر، حالت خالی و پر برنامه پرداخت، ثبت و بازخوانی مبلغ `9007199254740993.123456` و فرم ویرایش بررسی شدند. نماهای دسکتاپ و موبایل ۳۹۰ پیکسل بررسی شدند.
- نمونه PDF مالی و حقوق تولید، به تصویر تبدیل و از نظر جداکننده، فونت و چیدمان مشاهده شدند.
- این بررسی مرورگر نمونه‌های نماینده مسیر مشترک است؛ ادعای اجرای دستی همه صفحات و همه حالت‌های محصول یا پذیرش تخصصی مالی نیست. نصب و داده واقعی کاربر تغییر نکردند.
