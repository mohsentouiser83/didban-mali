# بررسی بازطراحی Drawerها

تاریخ: ۱۴۰۵/۰۷/۲۶

الگوی مشترک در `DetailField` و `ControlLabel` پیاده شده است: فیلد نمایشی ۶۴ پیکسلی، آیکون معنادار، کوتاه‌سازی متن بلند و دسترسی به متن کامل با اجزای tooltip مشترک. بخش‌های بازوبسته‌شونده از محتوای Drawerها حذف شده‌اند. ورودی چندخطی، پیام خطا و محدودیت محاسبه همچنان کامل نمایش داده می‌شوند.

## پوشش مرورگر داخلی

۲۷ حالت در دسکتاپ و موبایل ۳۹۰×۸۴۴ بررسی شد. در اندازه‌گیری‌ها، فیلدهای نمایشی ۶۴ پیکسل بودند؛ آیکون داشتند و بیرون‌زدگی افقی یا بخش محتوایی بازوبسته‌شونده مشاهده نشد.

| سطح | حالت بررسی‌شده |
| --- | --- |
| دوره مالی | ایجاد دوره و انتخاب/فیلتر دوره |
| وصول‌ها | حالت خالی واقعی و ویرایش پرشدهٔ آزمایشی |
| ورود فایل | جزئیات ورودی، انتخاب فایل، ردیف منبع، تطبیق ستون‌ها و اعتبارسنجی |
| گزارش | فرم خالی واقعی و فرم پرشدهٔ آزمایشی |
| اعضا | افزودن عضو |
| اتصال | فرم ایجاد و جزئیات/تاریخچهٔ پرشدهٔ آزمایشی |
| نقدینگی | جزئیات روز و برنامه پرداخت |
| مؤدیان | مقایسهٔ دوطرفه با داده آزمایشی |
| شواهد شاخص | داده، بارگذاری و خطا با بازیابی آزمایشی |
| تسویه بانکی | جزئیات و فرم تخصیص آزمایشی |
| مشتری/تأمین‌کننده | جزئیات و اسناد آزمایشی |
| دستیار مالی | پاسخ و فاکتورهای آزمایشی؛ پنل عمداً غیرمودال باقی مانده است |
| شواهد یافته | فیلدها و یادداشت آزمایشی |
| اجزای مشترک | متن بلند، مبلغ دقیق بزرگ، صفر، مقدار ناموجود و فرم نامعتبر |

نمونه‌های پرشده از همان اجزای محصول در صفحهٔ سیستم طراحی استفاده می‌کنند؛ درخواست‌های آن‌ها ساختگی‌اند. هیچ داده تجاری، تخصیص بانکی، عضو یا اتصال واقعی ایجاد نشد و پرسش دستیار به سرویس ارسال نشد.

## تعامل و کنترل کیفیت

- tooltip متن بریده با لمس و صفحه‌کلید، بسته‌شدن با Escape و باقی ماندن Drawer بررسی شد.
- بازگشت فوکوس پس از بستن Drawer، محصوربودن فوکوس در Sheet، انتخاب‌گر مشترک و نمایش خطای فارسی با تمرکز روی اولین ورودی نامعتبر بررسی شد.
- افزودن ردیف وصول و انتخاب تراکنش برای نمایش فرم تخصیص بدون ذخیره واقعی بررسی شد.
- مجموعهٔ اصلی ۲۷۶ آزمون موفق داشت؛ دو آزمون جدید فیلد مشترک و آزمون‌های دستیار پس از اصلاح نهایی نیز موفق بودند. بررسی TypeScript و ESLint انجام شد.
- محافظ‌های کاهش حرکت حفظ شده‌اند؛ آزمایش زنده با ترجیح کاهش حرکت سیستم‌عامل هنوز انجام نشده است.

این بررسی تأیید نهایی طراحی توسط کاربر محسوب نمی‌شود.
