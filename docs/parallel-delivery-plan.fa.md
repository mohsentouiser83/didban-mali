### مالکیت هماهنگ‌کننده در موج دوم

- فایل‌های مشترک قرارداد، مولد OpenAPI و schema تولیدشده، ترتیب migrationها، router مرکزی، worker orchestration، ناوبری و اجزای عمومی مشترک فقط به هماهنگ‌کننده سپرده می‌شوند. عامل‌ها patch یا نیاز اتصال را تحویل می‌دهند؛ هم‌زمان همان فایل را ویرایش نمی‌کنند.
- هر مسیر، تست domain و API و رابط خود را تحویل می‌دهد. هماهنگ‌کننده سه مسیر را روی یک بسته مصنوعی مشترک و نسخه سیاست یکسان وصل و آزمایش می‌کند؛ رفع اختلاف قرارداد پیش از ادامه مصرف‌کننده انجام می‌شود.
- نمونه‌های مرجع F01–F15، شواهد مالی immutable و نسخه‌های قبلی گزارش حفظ می‌شوند. افزودن/اصلاح ورودی یا برگشت تخصیص باید revision تازه بسازد؛ snapshot تاریخی بازنویسی نمی‌شود.
- ابهام ضروری همچنان کل بسته را در سرور متوقف می‌کند. بستن پنجره یا مرورگر، پاسخ فرضی یا ادامه شاخه مستقل ایجاد نمی‌کند. فهرست ماژول‌های نسخه تاریخی بازنویسی نمی‌شود؛ آمادگی حوزه‌های تازه از run و snapshot مستقل آن‌ها خوانده می‌شود.

## پذیرش نهایی با هماهنگ‌کننده

۱. خروجی مسیرهای عامل‌ها را روی قرارداد، migration و workflow مشترک ادغام کند؛ آزمون مستقل هر عامل را از آزمون یکپارچه و آزمون زنده تفکیک و نتایج واقعی را ثبت کند.

۲. مسیر کامل «بارگذاری → تفسیر → سؤال لازم → محاسبه → تطبیق/تخصیص → پیش‌بینی → خروجی → تأیید همان نسخه» را با داده مصنوعی و نقش‌های مالک، مدیر مالی، حسابدار/مشاور و مشاهده‌گر آزمایش کند. آزمون دسترسی بین دو شرکت و لغو مجوز هنگام عملیات الزامی است.

۳. رابط در مرورگر داخلی Codex روی دسکتاپ و موبایل بررسی شود: حالت پر/خالی/خطا/loading، سؤال پایدار، Escape و بازگشت focus، صفحه‌کلید، جدول/نمودار قابل مشاهده و reduced-motion واقعی. طراحی بنفش مصوب و اندازه/وزن فونت‌ها مبناست؛ نمونه تصویری تأییدشده نیازمند تأیید دوباره نیست.

۴. F01–F15 و سناریوهای زنجیره مؤدیان، تخصیص رقابتی، قطع مدل/سقف هزینه، بایگانی/حذف و بازیابی را با خروجی مرجع مقایسه کند؛ اختلاف مالی حل‌نشده، نتیجه نامعلوم یا تأیید حسابدار انجام‌نشده را به عنوان محدودیت صریح ثبت کند.

۵. فقط پس از شواهد معتبر، اسناد وضعیت و runbook را به‌روز کند. build موفق به‌تنهایی به معنی صحت مالی، نصب سازمانی، اتصال زنده مدل یا پذیرش نهایی نیست. نصب واقعی روی سرور سازمان و تأیید پذیرش آن تا زمان انجام، «انجام‌شده» ثبت نمی‌شود.
