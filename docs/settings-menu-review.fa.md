# منوی تنظیمات — ۲۰۲۶/۱۱/۰۱

منوی چرخ‌دنده در هدر دسکتاپ و موبایل جای گروه مدیریتی سایدبار و انتخابگر جداگانه واحد نمایش را گرفت. مقصدهای شرکت‌های من، اعضا و دسترسی، دوره‌های مالی و مصرف و هزینه مسیرهای مستقل قبلی را حفظ می‌کنند. مقصد مدل هوش مصنوعی فقط به مدیر نصب نمایش داده می‌شود؛ ورود مستقیم دیگر کاربران نیز کنترل‌های مدیریت را نمایش نمی‌دهد و API پیکربندی نصب، مجوز مدیر نصب را مستقل بررسی می‌کند.

واحد نمایش فقط ریال یا تومان است. انتخاب در مرورگر و به تفکیک شناسه کاربر حفظ می‌شود؛ داده اصلی مالی و واحد ورودی تغییر نمی‌کنند. صفحه شرکت‌های من فهرست شرکت‌های مجاز و انتخاب شرکت فعال را دارد. ساخت شرکت همچنان فقط در اختیار مدیر نصب است.

صفحه مستقل مدل وضعیت مشترک نصب، بودجه کل نصب و تعرفه/آمادگی و درخواست‌های شرکت فعال را دارد. نام مدل پشتیبانی‌شده، کلید و فعال‌سازی از محیط سرور خوانده می‌شوند؛ انتخاب مدل دلخواه یا واردکردن کلید از مرورگر اضافه نشده است. هیچ درخواست زنده‌ای به provider انجام نشد.

## بررسی انجام‌شده

- مرورگر داخلی Codex: منوی دسکتاپ ۱۴۴۰×۱۰۰۰ و موبایل ۳۹۰×۸۴۴؛ لینک فعال، نشان انتخاب واحد، تغییر واحد، حفظ انتخاب پس از reload، Escape و بازگشت فوکوس، بازکردن منو با ArrowDown و رفتن به صفحه شرکت‌ها با Enter.
- شرکت‌ها: نمایش دو شرکت ساختگی و انتخاب شرکت بدون داده؛ هدر و اطلاعات شرکت به انتخاب تازه تغییر کردند.
- مدل: پاسخ موفق وضعیت نصب، بودجه، آمادگی، تعرفه و درخواست‌ها در پایگاه آزمایشی تازه؛ حالت‌های خالی نمایش داده شدند. فرم بودجه با ارسال خالی پیام فارسی و فوکوس فیلد الزامی داشت؛ بودجه واقعی ثبت نشد.
- حساب مشاهده‌گر ساختگی: گزینه مدل در منو غایب بود؛ مسیر مستقیم `/settings/model` پیام محدودیت دسترسی داشت.
- Reduce Motion سیستم‌عامل موقتاً روشن شد: `matchMedia` برابر true، انیمیشن منو `none` و `transition-property` گزینه‌ها `none` بود. تنظیم سیستم سپس خاموش و viewport آزمایشی بازنشانی شد.
- خطای API نیز پیش از راه‌اندازی API تازه بررسی شد؛ اقدام تلاش دوباره قابل دسترسی بود. پایگاه QA قبلی با تغییرات جدید مدل داده سازگار نبود؛ داده یا schema آن تغییر نکرد. آزمون موفق با پایگاه ساختگی جدید `var/settings-qa/browser-qa.db` و فایل‌های مستقل اجرا شد. پایگاه اصلی و قدیمی بازنشانی نشدند.
- build تولیدی شامل TypeScript موفق؛ ۱۸ آزمون وب و lint موفق؛ ۵ آزمون API مدیریت مدل موفق. fixtureهای tooltip با شناسه الزامی سری در نسخه نصب‌شده Recharts هماهنگ شدند.
