# قرارداد فنی جاری دیدبان مالی

بازبینی: ۲۰۲۶/۱۱/۱۳. این نسخه جای طرح پیشنهادی ۰٫۱ را برای اجرای فعلی می‌گیرد؛ [نسخه پیشین](history/pre-doc-refresh-20261113/rebuild-technical-contract.fa.md) حفظ شده است. قواعد مالی و تصمیم‌های کاربر بر انتخاب‌های مهندسی مقدم‌اند.

## مرز اجرا

- مخزن فعال همین `didban-mali`؛ API: `apps/api/didban`، وب: `apps/web`. مسیر `apps/api/app` و migrationهای قدیمی مرجع اجرای تازه نیستند.
- FastAPI، SQLAlchemy Session و PostgreSQL؛ SQLite برای توسعه و بیشتر آزمون‌های واحد. معماری فعلی با ادعای async ORM یکسان نیست.
- وب Next.js/React/TypeScript با Tailwind و کنترل‌های مشترک، RTL فارسی و فونت‌های واقعی مصوب.
- صف پایدار در `outbox_jobs` و worker با lease/generation/fence؛ Redis/Celery در Compose جاری وجود ندارند.
- اصل فایل‌ها روی فضای خصوصی `DIDBAN_STORAGE` و volume `fresh_private` است؛ MinIO/S3 در Compose جاری وجود ندارد. scanner سرویس ClamAV است.
- نصب `didban-fresh`: PostgreSQL، scanner، api، worker و web؛ پورت وب میزبان ۳۰۰۰ و API ۸۰۰۰. volumeهای legacy دست‌نخورده می‌مانند.

## داده و اصلاح

مبلغ Decimal با `Money`، PostgreSQL `numeric(38,6)` و رشته دقیق API است. ریال/تومان، واحد و مبلغ خام مستقل‌اند؛ float، NaN و گردکردن خاموش مجاز نیستند. تاریخ مالی date و زمان رویداد UTC است. شرکت در FKهای مالی و کنترل service و RLS نقش محدود PostgreSQL محافظت می‌شود. SQLite اثبات RLS نیست.

اصل، تفسیر، تصمیم، سند نهایی و گزارش ثابت سابقه حفظ می‌کنند. revision، برگشت و جایگزین راه اصلاح‌اند؛ آرشیو منبع اثر تاریخی را پاک نمی‌کند. منبع فایل، دفتر بومی و فاکتور بومی هویت مستقل دارند و با manifest جعلی یا جمع دوباره مخلوط نمی‌شوند.

## امنیت و درخواست

نشست کوکی HttpOnly، کنترل CSRF و Idempotency-Key برای تغییرها؛ نسخه مورد انتظار طبق قرارداد هر endpoint. کنترل عضویت/مجوز در سرور و هنگام commit/تأیید تکرار می‌شود. مالکیت خودکار اختیار ثبت یا تأیید گزارش نمی‌دهد. اعطای اختیار مستقل ممیزی می‌شود. اسرار provider، توکن بات، PEM و traceback به مرورگر/لاگ عمومی نمی‌روند.

## پردازش و AI

هدف ورودی ۱۰ فایل/۲۰هزار ردیف، سقف جاری هر فایل ۲۰MiB و محتوای بازشده ۱۰۰MiB است؛ مقادیر دقیق در `config.py` هستند. محتوای سلول دستور نیست. تفسیر مدل فقط پیشنهاد ساخت‌یافته است؛ واحد، تقویم، خانواده و همه ردیف‌ها کنترل می‌شوند. سؤال ضروری مانع کل نوبت است، ولی نبود یک خانواده منبع به‌تنهایی مانع بخش مستقل نیست.

مدل فعلی کد `gpt-5.6-luna` با AvalAI پیش‌فرض و endpointهای مجاز است. مقصدهای مدل در `model_gateway.py` محدودند. رزرو/تعرفه/مصرف و هزینه نامعلوم مستقل از دفتر ریالی شرکت‌اند. HTTP مدل بدون بازماندن تراکنش DB اجرا و نتیجه با مجوز/نسخه/fence تازه کنترل می‌شود. حالت نامحدود تنظیم صریح نصب است و provenance/مصرف را حذف نمی‌کند. گفتار هزینه و فعال‌سازی جدا دارد.

## قرارداد، ارتقا و تحویل

مرجع ماشینی `contracts/openapi.json` و `database/schema.sql` است؛ ۱۱۴ جدول مدل، ۲۴۴ path و ۲۸۹ عملیات HTTP در بازبینی حاضر. `scripts/generate_contracts.py` snapshot می‌سازد. تغییر schema نیازمند مسیر ارتقای صریح و حفظ داده است؛ `create_all` جای migration داده‌دار نیست. کنترل readiness ناسازگاری را رد می‌کند و خودش مهاجرت عمومی نیست. [مدل](data-model.fa.md)، [API](api-contract.fa.md)، [گردش](workflow-contract.fa.md).

UI تغییرکرده باید در مرورگر داخلی، دسکتاپ/موبایل، صفحه‌کلید و کاهش حرکت واقعی بررسی شود. خروجی PDF باید رندر شود. پذیرش نصب پاک، PostgreSQL محدود، restart، اسکنر، restore و بار ۱۰ فایل/۲۰هزار ردیف/پنج کاربر نیازمند شواهد اجرای مستقل است؛ عدد SLA یا سخت‌افزار از اسناد قدیمی پذیرفته نیست.
