# اجرای موج دوم — ۲۰۲۶/۱۱/۰۲

وضعیت: بخش‌های مستقل ساخته و بررسی شده‌اند؛ کل دامنهٔ مصوب هنوز کامل نیست.

- سناریوی نقدینگی: مبنای ثابت، جابه‌جایی تاریخ، دریافت/پرداخت فرضی، نسخه‌های تغییرناپذیر، مقایسه پایان/کمترین مانده/کسری و ارزیابی گردش واقعی فقط با پوشش و حساب‌های سازگار. سناریو هیچ سند یا تعهد واقعی نمی‌سازد.
- پیگیری و همکاری: پرونده روی یافته/فاکتور واقعی، مسئول فعال، مهلت، وضعیت، دلیل، یادداشت/درخواست مدرک/نتیجه تماس/وعده، سابقه تغییرناپذیر و کنترل نسخه/شرکت. وعده وصول نیست. رتبه وصول فعلاً مبلغ مانده سپس روز تأخیر است؛ امتیاز مبتنی بر سابقه مشتری و ارسال پیام بیرونی ساخته نشده است.
- گزارش‌ساز: تعریف ساخت‌یافته، درخواست فارسی محدود، پیش‌نمایش، ذخیره تعریف، اجرای ثابت، اجرای دوباره و PDF/Excel. درخواست ترکیبی یا مبهم بدون حدس انتخاب می‌خواهد؛ مدل عددسازی و SQL آزاد ندارد.
- قواعد: شروط مجاز بدون کد، پیش‌نمایش ثبت‌شده با کاربر/تعریف/manifest، فعال‌سازی فقط با اثبات پیش‌نمایش، اعلان داخلی/ساخت پیگیری/درخواست تهیه پیش‌نویس، سابقه اجرا و جلوگیری از اثر تکراری. درخواست تهیه پیش‌نویس فقط اعلان است؛ سند مالی تولید نمی‌کند. انتشار manifest قواعد فعال را اجرا می‌کند؛ لغو دسترسی سازنده و خاموشی مطالبات مانع اقدام مرتبط‌اند.
- حافظه نگاشت: الگوی نام‌دار از اصلاح انسانی که واقعاً در manifest استفاده شده، نمایش نگاشت و منشأ، تغییر نام/خاموشی؛ استفاده دوباره فقط در ساختار دقیق همان شرکت و بدون کنارگذاشتن کنترل ردیف. واحد صریح متعارض/ارزی پوشانده نمی‌شود؛ نقش صریح جدید جایگزین نمی‌شود. این قابلیت یادگیری عمومی از همه رفتارها یا تطبیق خودکار هر قالب نیست.
- ناوبری: هیچ آیتم سایدبار اضافه نشد. سناریو از پیش‌بینی، وصول از مطالبات، گزارش‌ساز از گزارش‌ها و قواعد/حافظه از دستهٔ اسناد در چرخ‌دنده دسترس دارند. حالت فعال مسیرهای مرتبط حفظ شده است.

## بررسی ثبت‌شده

۲۷۱ آزمون API موفق، یک PostgreSQL اجرا‌نشده (نیازمند نقش آزمون جدا)؛ ۶۵ آزمون وب در ۲۱ فایل موفق؛ lint وب و build تولیدی جدا موفق. ۵۱ جدول و ۱۱۰ مسیر از کد تولید شدند. ۴۹ آزمون هدفمند قواعد/کنترل/سناریو/گزارش‌ساز نیز موفق بودند. نتیجه آزمون جای تأیید حسابدار یا پذیرش PostgreSQL نیست.

مرورگر داخلی روی SQLite و دادهٔ مصنوعی مستقل: قواعد خالی و غیرفعال‌بودن پیش‌نمایش بدون داده، نبود منبع سناریو، انتخاب شرکت، ذخیره سناریوی دارای مبنا، پیش‌نمایش و ذخیره گزارش با لینک خروجی، ساخت پرونده روی شاهد واقعی و نمایش فعالیت‌ها بررسی شدند. تصاویر در validation/expansion-v2/browser هستند. این بررسی پوشش کامل دسکتاپ/موبایل، کاهش حرکت، همهٔ خطاها یا همهٔ مسیرهای جدید نیست؛ QA تکمیلی باقی است. دادهٔ واقعی شرکت برای این آزمون دست‌کاری نشده است.

## کارهای باقی‌مانده

ثبت نهایی، قواعد عملیات و چک/اختتامیه وابسته به بررسی بسته حسابدارند و غیرفعال مانده‌اند. بات چندرسانه‌ای و تأیید/اعلان بات، تنظیم کاربرد شرکت، قالب و ورود کدینگ، چندبه‌چند کامل، تشخیص آماری ناهنجاری، حسابداری پروژه/مرکز هزینه، گروه شرکت‌ها/حذف درون‌گروهی و اتصال واقعی نرم‌افزار مبدأ هنوز تکمیل نشده‌اند. مقایسه گروه شرکت‌ها در این موج صرفاً طرح بود؛ هیچ مدل یا رابط آماده‌ای برای آن ادعا نمی‌شود. وضعیت P01–P28 نباید با وجود این موج «همه کامل» شود.
