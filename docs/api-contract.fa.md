# قرارداد API جاری

بازبینی کد: ۲۰۲۶/۱۱/۲۲. [OpenAPI تولیدشده](../contracts/openapi.json) با برنامهٔ جاری ۲۶۹ مسیر و ۳۲۹ عملیات HTTP دارد. مرجع اجرا `apps/api/didban/api.py` و `routes/` است. روش‌های متفاوت روی یک مسیر جداگانه شمارش می‌شوند.

## قواعد مشترک

مسیرهای شرکتی زیر `/api/v1/companies/{company_id}` هستند. عضویت/مجوز در سرور کنترل می‌شود. نشست HttpOnly، CSRF برای تغییرهای وابسته به نشست و Idempotency-Key در مسیرهایی که آن را مطالبه می‌کنند لازم است؛ نسخه مورد انتظار در body یا If-Match طبق schema همان عملیات ارسال می‌شود. همه مسیرها یک قرارداد نسخه فرضی مشترک ندارند. مبلغ رشته دقیق لاتین IRR، مقدار ناموجود null و تاریخ مالی ISO است. خطای دامنه کد و پیام فارسی دارد و اسرار/stacktrace برنمی‌گرداند.

مسیرهای سابق `/modules` بازنشسته شده‌اند. مجوز و اعتبار دادهٔ هر گردش در همان حوزه اعمال می‌شود.

## خانواده‌های موجود

| حوزه | قرارداد رفتاری |
|---|---|
| auth / شرکت / اعضا | حساب مدیریت‌شده بدون signup عمومی، عضویت جاری و اعطای ممیزی‌شده اختیارهای مستقل |
| periods / period-locks | CRUD، منع تغییر بازه استفاده‌شده، قفل و بازگشایی مجاز با دلیل |
| sessions / sources / processing | انتقال و seal، اسکن، نسخه، سؤال پایدار، ادامه تکرارپذیر و آرشیو وابسته |
| accounting | کدینگ/پیش‌نویس/عملیات، preview و تأیید دقیق برای ثبت، برگشت/جایگزین و گزارش دفتر. فهرست `/companies/{company_id}/accounting/journals` با `order_by_date=true` به‌ترتیب نزولی تاریخ سند صفحه‌بندی می‌شود. `period_id` فهرست را به دورهٔ همان شرکت محدود می‌کند. |
| accounting/native-invoices | شرایط، تخصیص و برگشت، پذیرش جایگزین و snapshot/خروجی ثابت |
| commercial / numbering | کارت طرف‌حساب، پیش‌فاکتور فروش و تبدیل یا خروجی. سابقهٔ خرید خواندنی است. تبدیل ناقص پیش‌فاکتور رد می‌شود. شماره‌گذاری مسیر مستقل دارد |
| inventory | زیر `accounting/inventory`؛ کالا و انبار، کاردکس صفحه‌بندی، ارزش‌گذاری، سود و پیش‌نویس تک‌قلم، افتتاحیه، انتقال و تعدیل |
| moadian-transmissions | تهیه/تأیید همان نسخه، ارسال و استعلام محدود، کنترل وضعیت نامعلوم و پاسخ معتبر |
| reconciliation | تطبیق بانک روی منبع ورودی یا دفتر بومی، انتخاب چندبه‌چند، تطبیق طرف‌حساب و مقایسه کارپوشه مؤدیان؛ درصد ناموجود هنگام صفر بودن مبنای فروش |
| native-forecasts / scenarios | منبع و سؤال/پاسخ نسخه‌دار، نتیجه و مقایسه ثابت، سناریو بی‌اثر مالی |
| reporting / report-builder | آرشیو، تأیید، خروجی گزارش، رجیستری منابع و تعریف گزارش. انتخاب داشبورد با `mode=fixed` پیش‌فرض است و `mode=live` انتخاب صریح است |
| control | پیگیری وصول، پرونده و فعالیت پیگیری، مسئول و مهلت |
| dimensions / groups / consolidation | تخصیص مدیریتی و مقایسه مجاز، حذف منتخب ۱۰۰٪ و تأیید مستقل |
| accounting/discussions | نظر/درخواست/مسئول/مهلت/وضعیت و سابقه؛ اختیار ثبت ایجاد نمی‌کند |
| employees / payroll / tax / insurance | مدیریت کارمند در `/employees` و دفترچهٔ منبع در `/personnel-directory` مسیرهای مستقل‌اند. پیش‌نویس لیست حقوق حساب‌های انتخابی و نسخهٔ مورد انتظار را می‌گیرد |
| assistant | انتخاب زمینه، پرسش، وضعیت صوت و تبدیل گفتار. عملیات پشتیبانی‌شده در پرسش دارای کنترل تکرار هستند. ثبت سند از مسیر مستقل پیش‌نمایش و ارسال نسخه و هش انجام می‌شود |
| document-archive/spreadsheets | بارگذاری اصل Excel/CSV ورودی جدول، فهرست و دریافت اصل فایل برای بارگذار در شرکت جاری. فایل کدینگ نیز پس از اعتبارسنجی در همین فهرست ثبت می‌شود. |
| bot-connections / bot-intakes | اتصال خود کاربر، استخراج/بررسی، تأیید مستقل سند و ارسال صریح PDF از `bot-connections/deliver-document` |
| admin / model | تعرفه، بودجه، مصرف، رزرو و شواهد مدل برای مدیریت نصب است و در تنظیمات محصول صفحه ندارد |

این جدول فهرست نام دقیق همه routeها نیست؛ روش HTTP، پارامتر، enum، خطا و response از OpenAPI جاری خوانده شود. فهرست routeهای قدیمی `apps/api/app` و آمار تاریخی راهنمای integration تازه نیستند.

## وب‌هوک و مدارک

تلگرام `POST /api/v1/bots/telegram/webhook` و secret header؛ بله `POST /api/v1/bots/bale/webhook/{secret}`. امنیت webhook مستقل از کوکی است. وضعیت اتصال، مدرک، استخراج و تأیید نهایی سند جدا هستند. هیچ پاسخ مدل یا پیام آزاد مجوز ثبت نیست. [بات‌ها](bots.fa.md).
