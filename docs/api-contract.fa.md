# قرارداد API جاری

بازبینی: ۲۰۲۶/۱۱/۱۳. مرجع ماشینی دقیق `contracts/openapi.json`، منبع `apps/api/didban/api.py` و `routes/` است. snapshot با OpenAPI کد برابر است: ۲۴۴ path و ۲۸۹ عملیات HTTP. عدد ۲۳۴ مربوط به موج پنجم است؛ endpointهای هم‌مسیر با روش متفاوت عملیات جدا دارند.

## قواعد مشترک

مسیرهای شرکتی زیر `/api/v1/companies/{company_id}` هستند. عضویت/مجوز در سرور کنترل می‌شود. نشست HttpOnly، CSRF و Idempotency-Key برای تغییرها لازم‌اند؛ نسخه مورد انتظار در body یا If-Match طبق schema همان عملیات ارسال می‌شود. همه مسیرها یک قرارداد نسخه فرضی مشترک ندارند. مبلغ رشته دقیق لاتین IRR، مقدار ناموجود null و تاریخ مالی ISO است. خطای دامنه کد و پیام فارسی دارد و اسرار/stacktrace برنمی‌گرداند.

## خانواده‌های موجود

| حوزه | قرارداد رفتاری |
|---|---|
| auth / شرکت / اعضا | حساب مدیریت‌شده بدون signup عمومی، عضویت جاری و اعطای ممیزی‌شده اختیارهای مستقل |
| periods / period-locks | CRUD، منع تغییر بازه استفاده‌شده، قفل و بازگشایی مجاز با دلیل |
| sessions / sources / processing | انتقال و seal، اسکن، نسخه، سؤال پایدار، ادامه تکرارپذیر و آرشیو وابسته |
| accounting | کدینگ/پیش‌نویس/عملیات، preview و تأیید دقیق برای ثبت، برگشت/جایگزین و گزارش دفتر |
| accounting/native-invoices | شرایط، تخصیص و برگشت، پذیرش جایگزین و snapshot/خروجی ثابت |
| inventory | کالا/انبار، summary و تهیه پیش‌نویس تک‌کالا؛ کاردکس صفحه‌بندی‌شده فعلاً نیست |
| moadian-transmissions | تهیه/تأیید همان نسخه، ارسال و استعلام محدود، کنترل وضعیت نامعلوم و پاسخ معتبر |
| reconciliation | مبنای فایل/دفتر بومی، پیشنهاد و preview، انتخاب چندبه‌چند، قبول/برگشت ظرفیت‌دار |
| native-forecasts / scenarios | منبع و سؤال/پاسخ نسخه‌دار، نتیجه و مقایسه ثابت، سناریو بی‌اثر مالی |
| reporting / report-builder | PDF/Excel از نسخه ثابت، مبنای صریح، تأیید جدا؛ parser فارسی محدود |
| control / automation / learning | کنترل قطعی، preview قواعد مجاز و پیشنهاد مبتنی بر اصلاح معتبر |
| dimensions / groups / consolidation | تخصیص مدیریتی و مقایسه مجاز، حذف منتخب ۱۰۰٪ و تأیید مستقل |
| accounting/discussions | نظر/درخواست/مسئول/مهلت/وضعیت و سابقه؛ اختیار ثبت ایجاد نمی‌کند |
| employees / payroll / tax / insurance | گزارش مالی واردشده؛ محاسبه/ارسال قانونی انجام نمی‌دهد |
| assistant | چت خواندنی؛ ارقام فقط facts ثابت و تاریخ‌دار، بدون ابزار تغییر اطلاعات |
| bot-connections / bot-intakes | اتصال خود کاربر، استخراج/بررسی، اعلان و تأیید سند در جریان مستقل |
| admin / model | تنظیم بودجه/تعرفه، مصرف، هزینه نامعلوم و شواهد پاسخ فقط با اختیار نصب/شرکت |

این جدول فهرست نام دقیق همه routeها نیست؛ روش HTTP، پارامتر، enum، خطا و response از OpenAPI جاری خوانده شود. فهرست routeهای قدیمی `apps/api/app` و آمار تاریخی راهنمای integration تازه نیستند.

## وب‌هوک و مدارک

تلگرام `POST /api/v1/bots/telegram/webhook` و secret header؛ بله `POST /api/v1/bots/bale/webhook/{secret}`. امنیت webhook مستقل از کوکی است. وضعیت اتصال، مدرک، استخراج و تأیید نهایی سند جدا هستند. هیچ پاسخ مدل یا پیام آزاد مجوز ثبت نیست. [بات‌ها](bots.fa.md).
