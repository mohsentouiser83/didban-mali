# بررسی کنترل‌های ورودی — ۲۰۲۶/۱۰/۱۵

تمام فایل‌های رابط در `apps/web` برای input، select و textarea خام و نوع ورودی‌های تخصصی بررسی شدند. صفحات و فرم‌ها از کامپوننت‌های پروژه استفاده می‌کنند؛ عناصر خام فقط داخل پیاده‌سازی پایه Input و Textarea باقی مانده‌اند.

## اصلاح‌ها

- انتخاب ماه و سال کتابخانه تقویم شمسی به Select مشترک متصل شد؛ منوی بومی مرورگر حذف و نگاشت انتخاب به تقویم حفظ شد. همه مصرف‌کنندگان PersianDatePicker این اصلاح را دریافت می‌کنند.
- انتخاب فایل به FileInput مشترک منتقل شد. کنترل قابل مشاهده Button پروژه است و ورودی فایل داخلی پنهان می‌ماند. نام فایل، انتخاب با صفحه‌کلید، فرمت‌های مجاز و حالت غیرفعال حفظ شدند.
- برچسب‌های اولویت، موضوع و شرح فرم پشتیبانی به کنترل‌های مربوط متصل شدند.
- قاعده بررسی کد علاوه بر تگ‌های خام، استفاده از نوع‌های بومی تاریخ، ساعت، checkbox، radio، range، color و file در Input صفحات را رد می‌کند. کنترل تخصصی باید از کامپوننت مشترک مربوط استفاده کند.

## بررسی در مرورگر داخلی

صفحات داشبورد، نقدینگی و پیش‌بینی، مطالبات، بدهی‌ها، بررسی و پیگیری، دوره‌های مالی، بارگذاری اسناد، دریافت و پرداخت، مؤدیان، گزارش‌ها، اتصال‌ها، اعضا، تعریف شرکت، ورود، ثبت‌نام و سیستم طراحی بررسی شدند. در نمونه‌های رندرشده، select بومی قابل مشاهده یا ورودی خارج از کامپوننت‌های پروژه یافت نشد.

تغییر ماه و سال و انتخاب روز، بازکردن منو با ArrowDown، بستن منو و تقویم با Escape و بازگشت تمرکز بررسی شد. انتخاب تاریخ در فیلتر مشترک مطالبات، اعمال بازه دلخواه و بازنشانی آن نیز بررسی شد. دکمه انتخاب فایل با Enter فایل‌گیر را باز کرد و نام فایل انتخابی و فعال‌شدن ادامه بررسی شد. فرم اعضا و پشتیبانی و انتخاب ماه شروع سال مالی نیز بررسی شدند. دعوت عضو، ارسال تیکت یا ثبت شرکت جدید انجام نشد.

تقویم و منوی ماه و فرم بارگذاری در عرض ۳۹۰ پیکسل و دسکتاپ بصری بررسی شدند؛ بیرون‌زدگی افقی مشاهده نشد. شاهدها و خلاصه بررسی DOM در `output/control-audit` قرار دارند. آزمون زنده تنظیم کاهش حرکت سیستم انجام نشده است.

## بررسی خودکار

هر ۲۲۴ آزمون فرانت‌اند در ۵۴ فایل گذشت. بررسی نوع‌ها و lint موفق بود. رد select خام و Input با نوع date نیز با اجرای مستقیم قاعده lint تأیید شد. selectهای داخلی پنهان Radix برای شرکت در فرم، کنترل قابل مشاهده مرورگر محسوب نمی‌شوند.
