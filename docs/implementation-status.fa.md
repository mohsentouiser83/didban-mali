## فاز ۹ — اولویت‌بندی و شواهد (بک‌اند)

**وضعیت:** بک‌اند تکمیل‌شده؛ رابط کاربری عمداً خارج از دامنهٔ فعلی
**تاریخ:** ۱۴۰۵/۰۶/۲۲

### خروجی‌ها

- score صدنمره‌ای قطعی بر پایه فرمول نسخه آغازین `۰٫۴۰×اثر + ۰٫۲۵×اهمیت + ۰٫۲۰×اطمینان + ۰٫۱۵×فوریت`
- چهار باند بحرانی، بالا، متوسط و پایین با مرزهای پایلوت قابل‌تنظیم و snapshot کامل config روی هر یافته
- breakdown مستقل هر عامل شامل امتیاز خام، وزن، سهم نهایی و دلایل فارسی
- سنجش اهمیت با ترکیب مبلغ مطلق و نسبت مبلغ به درآمد همان دوره؛ مبلغ به‌تنهایی مبنای رتبه نیست
- استفاده از مبلغ خود تراکنش برای missing/duplicate/date mismatch در صورت نبود اختلاف مبلغ
- جلوگیری از باند بحرانی برای یافته با confidence پایین و نمایش صریح عدم‌قطعیت
- نسخه مؤثر مدل اولویت با hash تنظیمات، مستقل از نسخه قواعد تولید یافته
- EvidenceItem به‌عنوان موجودیت درجه‌اول، مرتب، شرکت‌محور و تغییرناپذیر
- زنجیره شواهد برای هر یافته شامل قاعده و محاسبه؛ برای تطبیق تا رکورد کانونیکال، ردیف خام و فایل اصلی
- زنجیره روند مالی شامل metric دوره جاری، metric دوره قبل، محاسبات هر دو و فایل‌های snapshot تحلیل
- حفظ snapshot فیلدهای خام و نرمال مرتبط، محل شیت/ردیف، نام فایل و SHA-256
- API مشاهده شواهد یافته و فیلتر فهرست یافته‌ها بر اساس باند اولویت
- درج گروهی و idempotent شواهد، RLS، کلیدهای خارجی مرکب و ایندکس‌های FK/مسیر جست‌وجو

## فاز ۱۰ — داشبورد مالی (بک‌اند)

**وضعیت:** بک‌اند تکمیل‌شده؛ رابط کاربری عمداً خارج از دامنهٔ فعلی
**تاریخ:** ۱۴۰۵/۰۶/۲۲

### خروجی‌ها

- API خواندنی `GET /companies/{id}/dashboard` با انتخاب snapshot از طریق `analysis_run_id`، ماه میلادی یا آخرین اجرای تکمیل‌شده
- metadata ثابت دوره، وضعیت تحلیل، نسخه قواعد، زمان تکمیل و شناسه دوره هم‌طول مقایسه
- وضعیت سلامت دو‌بعدی: وضعیت مالی بر پایه بالاترین اولویت قابل اقدام و کیفیت داده به‌صورت مستقل
- تقدم قطعی باند بحرانی بر بالا، متوسط و پایین؛ score فقط درون هر باند ترتیب را تعیین می‌کند
- حذف `dismissed` و `resolved` فقط از Top Findings، با حفظ شمارش همه باندها و مسیر فهرست کامل
- شاخص‌های درآمد، سود، نقد، مطالبات، حاشیه، هزینه، دارایی، بدهی، حقوق مالکانه و فروش مستقیماً از MetricObservation
- روند و مقدار تغییر نسبت به آخرین دوره تکمیل‌شده و هم‌طول، با مدیریت صریح baseline صفر یا دوره مقایسه ناموجود
- اعلام صریح unavailable برای حساب‌های پرداختنی تا زمان تفکیک آن از سایر بدهی‌ها
- Main Drivers فقط از یافته‌های روند مالی مصوب و بدون اختراع finding یا تفسیر عددی تازه
- coverage بخش‌به‌بخش، امتیاز تجمیعی با روش نسخه‌دار و فهرست دلایل محدودیت تحلیل و موتور یافته
- خروجی Decimal به شکل رشته ثابت برای جلوگیری از خطای عددی در مصرف‌کننده
- دسترسی read-only برای تمام نقش‌های عضو شرکت و پنهان‌سازی کامل snapshot شرکت دیگر
- ایندکس مرکب و جزئی برای مسیر پرتکرار Top Findings قابل اقدام
