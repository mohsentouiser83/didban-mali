# کلاینت قرارداد

`schema.ts` با نسخه قفل‌شده openapi-typescript و `npm run generate:api` از قرارداد ریشه تولید می‌شود؛ دستی ویرایش نشود. نوع پول رشته می‌ماند؛ محاسبه مالی با Number اضافه نشده است.

`index.ts` مسئول cookie هم‌مبدأ، CSRF در حافظه با دریافت مشترک، Idempotency-Key، If-Match، خطای فارسی و اعلان انقضای نشست است. mutation retry خودکار ندارد؛ همان Command قابل استفاده مجدد است. hook مشترک `use-command.ts` برای خطای شبکه یا 5xx کلید را تا retry دستی همان payload نگه می‌دارد. خطای قطعی نسخه/دسترسی به‌صورت خودکار دور زده نمی‌شود.

نوع کامل API حوزه‌های آینده را هم دارد؛ این به معنی اجرای آن endpointها نیست. قرارداد زنده سرور فقط عملیات فعال را نشان می‌دهد. `npm run test:client` چهار سناریوی رفتار اتصال را می‌آزماید؛ آزمون مرورگر جداست.
