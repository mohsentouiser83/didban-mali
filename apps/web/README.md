# رابط اجرایی دیدبان مالی

Next.js 16.4.3، React 19.3.1، TypeScript و Tailwind 4.3.3؛ نسخه‌ها و وابستگی‌های غیرمستقیم در `package-lock.json` ریشه قفل شده‌اند. مبنا همان `design.md` و فونت‌های واقعی حفظ‌شده است.

صفحه‌های ورود، فعال‌سازی دعوت، بازیابی رمز، شرکت‌ها، نمای شرکت، تنظیمات، اعضا/مجوزها و کاربران سازمان پیاده‌اند. داده از API واقعی می‌آید؛ دوره‌های مالی، بارگذاری، پرونده آماده‌سازی، سؤال مسدودکننده و اعلان‌های داخل محصول نیز به API وصل‌اند. تفسیر، اصلاح نگاشت و صفحه شواهد هم ساخته شده‌اند؛ محاسبات پایه و صفحه ۱۲ شاخص، فهرست نسخه‌ها و شواهد هم متصل‌اند؛ تطبیق بانک/دفتر و مؤدیان، دریافت‌وپرداخت و برنامه تعهدات، مطالبات/بدهی تفکیک‌شده، نقدینگی و پیش‌بینی، بودجه/دستیار فقط‌خواندنی، گزارش‌ها و دانلود خروجی، سیاست‌ها و اصل فایل هم به API متصل‌اند. اتصال زنده مدل و پذیرش نهایی مرورگر/سازمان جداگانه‌اند؛ دامنه آزموده در گزارش هر بخش ثبت می‌شود.

- `features/*/*-view.tsx`: نمایش و state بصری فرم؛ controllerها و hookها مسئول درخواست، تبدیل ورودی و هماهنگی‌اند.
- `components/ui`: کنترل، فرم، اعتبارسنجی فارسی، Dialog/ConfirmDialog، جدول، badge، skeleton و notification مشترک.
- `app/api/v1/[...path]`: proxy هم‌مبدأ، بدون cache، با انتقال محدود header و چند Set-Cookie؛ secret و اتصال DB در وب وجود ندارند.
- `packages/api-client`: نوع‌های تولیدشده از قرارداد، دریافت CSRF، cookie، نسخه و کلید تکرار؛ نشست در storage مرورگر ذخیره نمی‌شود. mutation خودکار retry نمی‌شود؛ retry دستی پس از شکست نامطمئن، همان کلید و payload را حفظ می‌کند.
- query cache فقط حافظه است؛ خروج/تغییر حساب آن را پاک می‌کند و 401 معتبر، کاربر را به ورود برمی‌گرداند. ظاهر کنترل‌ها مجوز سرور را جایگزین نمی‌کند.

از ریشه مخزن: `npm ci`، `npm run generate:api`، `npm run typecheck`، `npm run lint` و `npm run build`. توسعه: `npm run dev`؛ اجرای build: `npm start`. مقدار `DIDBAN_API_ORIGIN` فقط در سرور وب و `DIDBAN_PUBLIC_ORIGIN` در API تنظیم می‌شود. راهنمای کامل در `docs/web-runtime.fa.md` است.

گزارش‌ها، سیاست‌ها و منابع مقصد مستقل دارند؛ دانلود باینری از proxy هم‌مبدأ با `Content-Disposition` و بدون cache عبور می‌کند. وضعیت پردازش تا آماده‌شدن سه خروجی واقعی دنبال می‌شود. مرجع فعلی [وضعیت اجرا](../../docs/implementation-status.fa.md) است.
